Try it in your browser

Seven steps on your own chain. Every click signs real secp256k1 transactions and mines a real block. MEME here is a test token with no value.

  1. 1

    Create wallets

    Three key pairs, kept in this browser. Hot signs and spends, cold only receives, the test buyer is your counterparty.

  2. 2

    Mine 5 blocks

    Each block pays 50 MEME to your hot wallet.

  3. 3

    Inscribe a meme

    The image's SHA-256 goes into a transaction. Fee 1 MEME. Each picture can be inscribed once.

  4. 4

    Put it up for sale

    A signed listing with your price.

  5. 5

    Let the test buyer buy it

    The buyer mines for MEME if needed, pays you and becomes the owner.

  6. 6

    Move 75% to the cold vault

    Hot keeps a small float, cold holds the rest. Top the hot wallet up when it runs low.

  7. 7

    Verify everything

    Replays your chain from genesis and checks every hash, signature and balance.

How the chain works

Two programs share one set of rules: node.py runs the testnet, chain.js runs the same rules in your browser.

Proof of work

Double SHA-256 over the block header, like Bitcoin. Difficulty retargets every 10 blocks toward one block a minute. 50 MEME per block, halving every 100,000 blocks.

Memes by hash

A meme transaction commits the picture's SHA-256, size and caption. The first inscription wins, ownership moves with signed sell and buy transactions.

Anchored in Bitcoin

Every 10th testnet block hash is stamped with OpenTimestamps, so a rewrite of older blocks is detectable against Bitcoin.

Testnet bot

A GitHub Actions job mines a few blocks every 20 minutes and inscribes memes from a public pool. Add yours with a pull request.

Run your own node
git clone https://github.com/larajeftic/memechain
cd memechain
pip install flask requests ecdsa pillow opentimestamps-client
python node.py            # explorer and API on http://localhost:5050

MEME is a test token. It has no value, is not sold and cannot be bought with money. The browser chain is a demonstration, not a network: every visitor builds their own, and the buyer is a second key in the same browser. The testnet is a small CPU-mined chain that only grows while the bot or a node runs it.
