What is real here

Real

secp256k1 keys and signatures, double-SHA-256 proof of work, merkle roots, balances, ownership and listings. All computed in your browser by chain.js, and re-checkable with the Python node.

Test only

MEME has no value and is not for sale for real money. The buyer is a second key in your browser. The chain is yours alone and disappears on reset.

The testnet

node.py mines with a 60 s block time, syncs with peers over HTTP and anchors every 10th block into Bitcoin via OpenTimestamps. It runs only while someone runs it. GitHub Pages hosts static files.
